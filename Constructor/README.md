Constructor

- Constructor name is same as Class name .
- If you don't write any constructor in a class, the compiler provides a default constructor automatically.
- If you write any constructor yourself, the compiler does not provide the default constructor.


Java constructors can be broadly described as:
1 ) Default constructor — provided by the compiler when you don't declare any constructor.
2 ) No-argument constructor — a constructor with zero parameters, which can be written by the programmer.
3 ) Parameterized constructor — a constructor that accepts one or more parameters.

Important distinction :- 
Default constructor ≠ No-argument constructor
